## About the Project

This project was completed for **WGU’s D799 – Mobile and Ubiquitous Design**, focusing on the creation of a **mobile application design plan** for *Campus Connect* — an integrated academic platform that unifies class schedules, grades, announcements, and peer communication. The goal was to enhance student engagement and time management by consolidating fragmented academic tools into one intuitive mobile experience.

## Course Information

**Course:** D799 – Mobile and Ubiquitous Design

## Project Overview

### Problem and Solution

University students often face fragmented access to schedules, grades, and communication channels. **Campus Connect** solves this by unifying all academic resources into a single mobile platform, reducing missed updates and improving academic organization.

### Key Features

* **Schedule Viewer:** Displays daily and weekly class times.
* **Grades & Announcements:** Consolidated view of academic progress and instructor updates.
* **Messaging Forum:** Direct student–professor communication within the app.
* **Push Notifications:** Alerts for class changes, new grades, and upcoming events.

### Technical Architecture

* **Framework:** .NET MAUI (cross-platform Android/iOS)
* **Local Storage:** SQLite for offline access
* **Cloud Sync:** Secure API with encrypted communication
* **Backend:** Modular architecture supporting future expansion (e.g., library access, event tracking).

### Connectivity and Device Integration

* **Wi-Fi / Cellular:** Enables real-time sync and notifications.
* **Bluetooth:** Optional peer-to-peer note sharing.
* **Calendar Integration:** Syncs course events with the device’s native calendar.
* **Push Notifications:** Provides timely academic reminders even when the app is closed.

### Security and Privacy

* TLS/HTTPS encryption for all data transmissions.
* Role-based access control (students vs. professors).
* Explicit user consent for all data collection and sharing.
* No third-party data access; anonymized data for analytics only.

### UI and UX Design

The app uses a clean, minimalist layout for intuitive navigation:

* Centralized dashboard for schedules, grades, and messages.
* Large, readable text and accessible color contrast.
* Usability testing with students and faculty to refine flow and accessibility.

### Performance Optimization

* Efficient API requests and caching to minimize data usage.
* Reduced background tasks to conserve battery life.
* Asynchronous updates for smooth navigation during data loading.

## Learning Summary

This course emphasized **mobile usability, device interactivity, and data-driven design**. Through Campus Connect, I developed skills in mobile UX architecture, cloud synchronization, and ethical mobile computing—core competencies for modern application development.
